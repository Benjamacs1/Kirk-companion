# Kirk Client GUI font

`Squares-Bold.ttf` is an unchanged copy of Kirk Client's `src/client/resources/assets/kirk_client/font/squares_bold.ttf`, loaded by `KirkGuiFonts.java`.

SHA-256: `0df9ac1fdc02c3bb8accce5aa3bae59558c2d30301d61d5690dde1177dac604e`.

Embedded font metadata: Squares Bold; Copyright (c) 2014 by Typetype. Designer Ivan Gladkikh, technical designer Olexa Volochay. All rights reserved. License: `sil ofl 1.1`. The unmodified font retains that license; it is not covered by the app's MIT license. See OFL-Squares.txt.

The app embeds this font as its primary proportional face, with egui's default fonts as missing-glyph fallbacks. No network font requests or installed system fonts are required.
